# Jupyter Notebooks Directory

This folder contains experimental Jupyter notebooks for:
- `01_eda_and_data_cleaning.ipynb`: Exploratory Data Analysis of CICDDoS2019 / CICIDS2017 network datasets.
- `02_feature_selection.ipynb`: Feature ranking and selection analysis.
- `03_model_training_and_comparison.ipynb`: Benchmark comparison of Machine Learning models.
